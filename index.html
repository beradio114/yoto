ヨット（ヤッツィー形式）のルール

各プレイヤーは1ターンに設定回数（標準3回、最大10回）まで5つのサイコロを振れます。途中で好きなサイコロをホールド（固定）して残りを振り直せます。

上段（1〜6の目）

該当する目の合計点が入ります。上段6項目の合計が設定したしきい値以上になると設定した上段ボーナス点数が加算されます！

下段（役）
  • スリーカード：同じ目3つ以上 → 全ダイス合計
  • フォーカード：同じ目4つ以上 → 全ダイス合計
  • フルハウス：3つ同じ＋2つ同じ → 25点
  • 小ストレート：4つ連続の目 → 30点
  • 大ストレート：5つ連続の目 → 40点
  • ヨット（ヤッツィー）：5つすべて同じ目 → 1:70点 / 2:65点 / 3:60点 / 4:55点 / 5・6:50点
  • チャンス：どんな目でもOK → 全ダイス合計

すでにヨットを獲得している状態で再度ヨットを出すと、その出目のヨット基本点（50〜70点）＋設定したヨットボーナスが加算されます。さらに「ヨットジョーカー」が有効な場合、2回目以降のヨットは下段の役（フルハウス・小ストレート・大ストレート）を代用として埋められます（上段の1〜6の目は、実際に出た目に対応するマスのみ通常通り5個分の点数が入ります）。
